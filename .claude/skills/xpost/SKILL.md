# xpost — XAgent投稿フロー

ユーザーが思いついた内容をXの投稿に整形し、**承認を経て**投稿する。完全自動はしない（X規約・凍結回避）。

CLIは `xagent`（リポジトリの venv で `pip install -e .` 済み前提）。DBはローカルSQLite。

## 標準フロー
1. **整形**: ユーザーのテキストを下書き化する。
   `xagent compose "<ユーザーが言った内容>"`
   - 長文で「さらに表示」を狙う場合のみ `--long` を付ける（既定は折りたたみ回避）。
   - 出力の下書き番号 `#<id>` と整形結果（スレッドなら複数セグメント）をユーザーに提示する。
2. **確認/修正**: ユーザーに整形結果を見せ、OKかを尋ねる。修正指示があれば再度 `compose` し直す。
3. **承認**: ユーザーがOKしたら `xagent approve <id>`。
4. **投稿 or 予約**:
   - 今すぐ: `xagent post <id>`
   - 最適時間に予約: `xagent queue <id>`（指定時刻は `--at <ISO>`）

## 受信対応
- 監視を回す: `xagent monitor-once`（メンション返信案・有名人への絡み案を下書き生成）
- 一覧: `xagent list --status draft` → 返信/絡み案を確認 → `approve` → `post`

## 対象・口調
- 絡む相手を追加: `xagent targets-add @handle`
- 口調を指定: `xagent style-set "<スタイルガイド>"` / 過去投稿から学習: `xagent learn`

## 重要な原則
- **承認なしに `post` しない**。必ずユーザーの承認を得てから投稿する。
- 投稿頻度ガード（1日上限・連投間隔）に引っかかったら理由をユーザーに伝える。
- X/Anthropicの資格情報が未設定なら、`.env`（`env.example`参照）の設定を案内する。
